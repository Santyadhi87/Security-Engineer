# Security Engineer
A Security Engineer is a cybersecurity professional who designs, builds, and maintains secure systems, networks, and software that makes sure security is built in from the start, not added as an afterthought. Unlike a penetration tester who attacks systems to find weaknesses, or a SOC analyst who monitors live threats, a Security Engineer focuses on prevention which setting up the right architecture, encryption, access controls, and hardening so that attacks are difficult to succeed in the first place. They work across the entire system lifecycle, from design through to incident response, and are essential in any organisation that handles sensitive data that exactly like Pathfinder, where you've already been doing security engineering by building RBAC, encryption, audit logging, and threat modelling into the platform from day one.

## Learning Objective
- Security engineering fundamentals — career paths, security principles, cryptography, and IAM
- Threats and risks — governance, regulation, threat modelling, risk management, and vulnerability management
- Network and system security — secure architecture, Linux/Windows/AD hardening, network protocols, cloud security, and monitoring
- Software security — OWASP API Top 10, SSDLC, SAST, DAST, DevSecOps, and weaponizing vulnerabilities
- Managing incidents — incident response, logging, first responder skills, and cyber crisis management
- OWASP Top 10 (2025) — IAAA failures, application design flaws, and insecure data handling
